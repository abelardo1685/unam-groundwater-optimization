# Skill: generar-practica

Genera el ejercicio práctico evaluable para la unidad `$ARGUMENTS` (unidades 3–7, 10% c/u).

## Pasos

1. Lee `app/routers/unidad_$ARGUMENTS.py` para entender los conceptos trabajados.
2. Diseña un ejercicio aplicado a aguas subterráneas con: enunciado, datos de entrada provistos, espacio para solución Python, preguntas de análisis.
3. Crea `app/routers/practica_$ARGUMENTS.py` con el ejercicio y solución separada por `# --- SOLUCIÓN ---`.
4. Crea `tests/test_unidad_$ARGUMENTS.py` con asserts que validen la solución del estudiante.
