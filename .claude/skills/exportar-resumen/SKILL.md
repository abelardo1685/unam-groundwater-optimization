# Skill: exportar-resumen

Consolida todo el material de la unidad `$ARGUMENTS` en un documento de resumen final.

## Pasos

1. Lee `docs/unidad_$ARGUMENTS/notas/resumen.md` y `literatura.md`.
2. Revisa `app/routers/unidad_$ARGUMENTS.py` para incluir los ejercicios clave.
3. Genera `docs/unidad_$ARGUMENTS/notas/resumen_final.md` estructurado como: objetivos, conceptos, ejemplos Python, referencias.
4. Opcionalmente convierte a PDF si `pandoc` está disponible.
