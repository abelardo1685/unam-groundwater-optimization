# Skill: revisar-practica

Revisa y califica la entrega del estudiante para la unidad `$ARGUMENTS`.

## Pasos

1. Lee `app/routers/practica_$ARGUMENTS.py` (solución de referencia).
2. Pide la ruta del archivo entregado si no se especifica como segundo argumento.
3. Ejecuta `tests/test_unidad_$ARGUMENTS.py` contra el archivo del estudiante.
4. Genera `docs/unidad_$ARGUMENTS/notas/retroalimentacion.md` con: aciertos, errores, sugerencias, calificación /10.
