# Context

Archivos de contexto que se cargan automáticamente al inicio de sesión.
Complementan al `CLAUDE.md` raíz con información más detallada o dinámica.

## Archivos

| Archivo | Propósito |
|---|---|
| `progress.md` | Estado actual del curso: qué unidades están completas |
| `decisions.md` | Decisiones de diseño tomadas (evita re-discutirlas) |
| `student_notes.md` | Observaciones sobre el grupo (anonimizadas) |
